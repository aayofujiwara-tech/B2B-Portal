## タスク1：利用規約ページの作成（`/terms`）

### 1-1. ページ作成

```
app/terms/page.tsx  （または pages/terms.tsx）
```

### 1-2. コンテンツ

確定済みの `eesumai_policy.md` の全文をこのページに表示する。

### 1-3. 構成

ページは **2セクション構成** とする：

```
┌─────────────────────────────────────┐
│  ヘッダー（既存のサイト共通ヘッダー）    │
├─────────────────────────────────────┤
│                                     │
│  利用規約・個人情報取扱特約             │
│  最終更新日：2026年2月16日             │
│                                     │
│  第1章〜第4章（本文全文）              │
│                                     │
├─────────────────────────────────────┤
│  【別紙】入居候補者様向けご案内          │
│  ※ 折りたたみ（アコーディオン）可       │
├─────────────────────────────────────┤
│  フッター（既存 + リンク追加）          │
└─────────────────────────────────────┘
```

### 1-4. スタイル方針

- 既存サイトのデザインシステム（フォント、カラー、余白）を踏襲
- 条文番号はそのまま表示（第1条、第2条…）
- 太字（`**`）部分は `<strong>` で表示
- 別紙はアコーディオン or 区切り線で視覚的に分離
- 印刷対応：`@media print` でヘッダー・フッター非表示、A4最適化

### 1-5. メタ情報

```tsx
export const metadata = {
  title: '利用規約・個人情報取扱特約 | ええすまい',
  description: 'ええすまい 紹介業者・MSW向けポータルサイトの利用規約および個人情報取扱特約',
  robots: 'noindex, nofollow'  // B2Bポータルのためインデックス不要
};
```

## タスク2：入居判定フォームへの同意チェックボックス追加

### 2-1. 追加場所

入居判定フォーム（トップページ `/`）の **「入居可能性を確認する」ボタンの直上**

### 2-2. 追加するUI要素

```
┌─────────────────────────────────────────────────┐
│  ☐ 利用規約・個人情報取扱特約 に同意します        │
│                                                  │
│  ☐ 入力する情報について、入居候補者ご本人          │
│    （または正当な代理人）から提供の同意を           │
│    得ていることを確認します                        │
│                                                  │
│  ※ 本フォームでは疾患・ADL等の要配慮個人情報を     │
│    取り扱います。送信前に必ず上記をご確認ください。  │
│                                                  │
│  [  入居可能性を確認する  ]  ← 両方チェックで活性化 │
└─────────────────────────────────────────────────┘
```

### 2-3. 実装仕様

```tsx
// state
const [agreedTerms, setAgreedTerms] = useState(false);
const [agreedConsent, setAgreedConsent] = useState(false);
const canSubmit = agreedTerms && agreedConsent;
```

**チェックボックス1（規約同意）：**
- ラベル：`利用規約・個人情報取扱特約に同意します`
- 「利用規約・個人情報取扱特約」部分は `/terms` へのリンク（別タブで開く）
- `target="_blank"` + `rel="noopener noreferrer"`

**チェックボックス2（本人同意の確認）：**
- ラベル：`入力する情報について、入居候補者ご本人（または正当な代理人）から提供の同意を得ていることを確認します`

**注意書き：**
- チェックボックスの下に小さめのフォントで表示
- テキスト：`※ 本フォームでは疾患・ADL等の要配慮個人情報を取り扱います。送信前に必ず上記をご確認ください。`

**送信ボタン：**
- 両方のチェックボックスがONの場合のみ `disabled={false}`
- 未チェック時はボタンをグレーアウト + `cursor-not-allowed`
- 未チェックでボタンクリック時はチェックボックスにバリデーションエラー表示

### 2-4. 送信データへの記録

フォーム送信時のペイロードに以下を追加：

```json
{
  "agreed_terms": true,
  "agreed_consent": true,
  "agreed_at": "2026-02-16T10:30:00.000Z"
}
```

これをバックエンド（Google Sheets / DB）に保存し、**同意の証跡**を残す。

## 規約コンテンツの管理方針

### 選択肢A：Markdownファイルとして管理（推奨）

```
public/legal/terms.md   ← 規約のMarkdown原本
```

- ビルド時または実行時に読み込み、`react-markdown` 等でレンダリング
- 規約の更新はMarkdownファイルの差し替え + デプロイのみ
- Gitで変更履歴を管理できる

### 選択肢B：TSXに直接記述

- シンプルだが規約の更新時にコード変更が必要
- 規約が長文のため保守性に劣る

**→ 選択肢Aを推奨**

## 注意事項

1. **同意の証跡は必ず保存する** — 「いつ・誰が・何に同意したか」のログは、万が一の紛争時に当社を守る最も重要な証拠。タイムスタンプ付きで保存すること。

2. **規約の更新日を表示する** — `/terms` ページの冒頭に「最終更新日」を必ず表示。更新時は日付を変更してデプロイ。

3. **ポータルサイトの電話番号について** — サイト本体の緊急連絡先（070-3244-5497・担当：生田）は入居相談の直通として残す。規約上の正式な問い合わせ窓口（06-4400-2901）とは役割が異なる。

4. **管理画面（`/admin`）への影響** — 管理画面は社内利用のため、同意チェックボックスの追加は不要。ただしフッターの規約リンクは表示する。
